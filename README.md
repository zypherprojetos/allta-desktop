# Allta para Windows (beta)

Instalador do programa do Allta para Windows: o sistema do restaurante numa
janela própria, com impressão direta de cupom e comanda, e o PDV vendendo
mesmo quando a internet cai.

**Baixar:** [Allta-Setup.exe](https://github.com/zypherprojetos/allta-desktop/releases/latest/download/Allta-Setup.exe)
— para Windows 10 ou 11 (64 bits). O programa se atualiza sozinho.

Versão beta: já funciona, e ainda recebe ajustes, que chegam sozinhos pela
atualização automática.

Este repositório guarda só o instalador. Mais informações em
[allta.com.br](https://allta.com.br).
